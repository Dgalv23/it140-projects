## Theme and Storyline

**Theme:**

Cyber Siege ? A cybersecurity adventure where the player must navigate a compromised computer network, collect security tools, and stop a hacker before the entire system is taken over.

**Storyline:**

A hacker has breached a company's computer network and is attempting to take control of its critical systems. The player is a cybersecurity specialist who must navigate through different areas of the network and collect six security tools needed to stop the attack. The player must gather all six tools while avoiding the hacker's location. Once all of the tools have been collected, the player can confront the hacker and secure the network.

## Rooms

Project One requires a minimum of eight rooms.

1. Security Operations Center - Start room
2. Server Room
3. Network Operations Center
4. Data Center
5. IT Help Desk
6. Firewall Control Room
7. Backup Server Room
8. Hacker's Command Center - Villain room

## Items

With the minimum eight-room design, Project One requires at least six items.
Every room except the start room and villain room must contain one item.

1. Encryption Key
2. Network Scanner
3. Security Token
4. Antivirus Software
5. Firewall Patch
6. Backup Drive

## Villain

GhostByte - A skilled hacker who has breached the company?s network and is attempting to take control of its critical systems. The player must collect all six security tools before entering GhostByte?s Command Center and stopping the cyberattack.
